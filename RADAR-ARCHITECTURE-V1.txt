CIKUR GO — INTERNAL LIVE RADAR ARCHITECTURE V1

Purpose
- Add an internal BCGO Radar Engine without changing the CGO reasoning brain contract.
- Radar is a state/visualization support organ, not an external AI and not a repair/execution organ.
- Customer detection remains CUSTOMER_GEO_SCOPED and never receives Agent coordinates.

New support module
- brain/cgo-ai-radar.js
- Owns Radar State Contract, presence normalization, freshness classification,
  JOIN/UPDATE/MOVE/STATUS_CHANGE/STALE/OFFLINE/LEAVE event derivation,
  internal admin snapshot, and customer-safe snapshot.

State pipeline
Agent CGO presence
  -> cikur-config.js / internal Firestore presence
  -> BCGO realtime presence feed
  -> cgo-ai-radar.js
  -> Radar State
  -> future BCGO Radar UI

Customer pipeline
Customer location
  -> CGO Customer Discovery
  -> CUSTOMER_GEO_SCOPED resolver
  -> internal spatially scoped presence query
  -> customer-safe result
  -> no Agent coordinates

Radar contract
- Scope: BCGO_ADMIN_RADAR
- Rings: 1 / 3 / 5 / 10 km
- Max internal agents: 500
- Freshness: 180 seconds
- Stale threshold: 180 seconds
- Offline threshold: 360 seconds
- Max accepted accuracy: 1000 m
- Event model: JOIN_UPDATE_MOVE_STATUS_STALE_OFFLINE_LEAVE
- Customer coordinate exposure: false

Status model
READY  = active + usable location + fresh + available
BUSY   = active + usable location + fresh + unavailable
STALE  = active but presence older than freshness window
OFFLINE= inactive or beyond offline threshold / unusable presence

Important boundary
- Radar does not perform source mutation, patch, approval, rollback, or execution.
- Medicine/Executor architecture is not reintroduced into BCGO.
- Real Firebase Rules, deployed multi-device E2E, and production load testing remain deployment-stage validation.

V3 VISUAL STATE LAYER
- cgo-ai-radar-visual.js converts trusted internal Radar State into deterministic UI primitives.
- Rings: 1/3/5/10 km.
- Marker states: READY/BUSY/STALE/OFFLINE.
- Event animations: JOIN=PULSE_IN, MOVE=MOVE, STATUS_CHANGE=STATUS_TRANSITION, UPDATE=HEARTBEAT, LEAVE=FADE_OUT.
- Customer-safe state contains no coordinates.
- No external map SDK is required; rendering remains a later UI responsibility.
