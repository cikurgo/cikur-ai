No remote GitHub/API write path is invented. A browser page cannot mutate a
GitHub Pages deployment without an authorized write service; this architecture
therefore refuses to report deployment success when only IndexedDB/browser
state changed.

Anti-loop rule:
  Executor is downstream of Medicine. Executor is never a prerequisite for
  Medicine to begin investigation. Repeated BLOCKED status without a new
  evidence/revision token must not recursively create another investigation.

Cache contract:
  All CIKUR GO internal modules in this milestone use the same hard-cut cache
  revision. Mixed query-string module copies are prohibited because they can
  create duplicate bridge/runtime instances in the same browser session.
