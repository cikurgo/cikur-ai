CIKUR GO — REAL REPAIR AUDIT
Date: 2026-09-17

This package is a code repair of the application package. It preserves the existing
Customer / Mitra / Internal page separation and does not make bcgo-admin.html a
prerequisite for index.html.

REAL FIXES IN THIS PACKAGE
1. Restored dedicated Firebase namespaces:
   - Customer/Mitra: CIKUR_GO_CUSTOMER -> auth/customerDb
   - Super Admin/Internal: CIKUR_GO_ADMIN -> adminAuth/adminDb
   - db remains an alias for customerDb for legacy Customer/Mitra code.
2. Rebound internal/bcgo.js to adminAuth/adminDb. BCGO must not authenticate as
   the Customer namespace.
3. Browser Brain ask() is synchronous for the Customer gateway and no longer
   calls CGO.chatAsync() recursively.
4. Application bootstrap explicitly connects the internal Brain to window.CGO.
5. BCGO state is mirrored through BroadcastChannel + localStorage so Customer CGO
   can consume the latest internal BCGO telemetry when both pages share the same
   origin.
6. Discovery has a bounded timeout so a live-radar check cannot leave the chat
   pipeline pending forever.
7. index.html cache-bust was advanced for the repaired Firebase config.
8. bcgo.html cache-bust was advanced for the repaired admin-auth BCGO engine.

VERIFICATION
- JavaScript syntax check: PASS for all JS files in this package.
- Internal Brain smoke test: PASS.
- Brain.ask() returns a synchronous response object and does not recurse into
  Customer chat.
- BCGO engine references adminDb/adminAuth after repair.

NOT CLAIMED
- Firebase live login cannot be authenticated in this offline build environment
  with the user's account/session.
- Browser production E2E with the live Firebase project is not claimed as PASS.
- Existing repository root image assets are intentionally not fabricated or
  replaced. The application pages retain their relative references to the root
  assets already present in the CIKUR GO repository.
