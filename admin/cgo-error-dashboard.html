Cara baca dashboard ini

1. Gejala — pesan error yang muncul (runtime, organ, scanner).

2. Lokasi — file + baris + kolom bila browser/stack memberikannya.

3. Relasi — dari source scan: file A tidak terhubung ke file B (UNKNOWN/MISMATCH).

4. Akar — hipotesis ringkas: relasi putus, referensi runtime, atau cross-origin.

5. Mesin ABC — pipeline A→B→C→D menilai kasus lalu ditulis ulang dalam bahasa yang mudah dipahami (status, keyakinan, saran).

Buka berdampingan dengan bcgo.html agar BCGO_STATE mengalir ke dashboard ini (BroadcastChannel + poll).
