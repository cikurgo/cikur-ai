- Number / letter / code / emoji / color spelling (8 languages)

## Usage

### Node (CJS)
```js
const { urai, nalar, cipta_ide } = require("./cikur-go.js");
// or with extension
const installV3 = require("./cikur-v3-extension.js");
const api = installV3(require("./cikur-go.js"));
```

### ESM
```js
import { urai, nalar } from "./cikur-go.mjs";
```

### Browser
```html
<script src="cikur-go.browser.js"></script>
<script>
  console.log(CIKURGO.urai("Halo 42", "auto", "id"));
</script>
```
