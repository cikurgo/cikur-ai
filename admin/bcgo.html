⚠️ HALAMAN DIBUKA LANGSUNG DARI FILE (file://)
Browser memblokir pembacaan antar file (source dan koneksi) kalau halaman ini dibuka dengan cara double-click. Ini pembatasan keamanan browser, bukan bug kode.

Solusi: jalankan server lokal di folder ini, lalu buka lewat http://localhost, bukan file://. Contoh (pilih salah satu):

python -m http.server 8000
npx serve .

Lalu buka http://localhost:8000/bcgo.html di browser.
