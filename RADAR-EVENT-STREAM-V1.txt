CIKUR GO — RADAR EVENT STREAM V1

Purpose
- Internal BCGO radar event stream for live Agent CGO monitoring.
- Event stream is generated by cgo-ai-radar.js from presence snapshots.
- No external AI/API and no Medicine/Executor dependency.

Events
- JOIN: agent appears in current presence feed.
- UPDATE: heartbeat/metadata update without meaningful movement.
- MOVE: meaningful movement >= 25 m.
- STATUS_CHANGE: READY/BUSY/STALE/OFFLINE transition.
- LEAVE: agent disappears from the current feed.

Safety
- Internal BCGO radar snapshot may contain Agent coordinates.
- Customer-safe snapshot contains no location/coordinate/accuracy fields.
- Customer discovery remains GEO-scoped and does not receive the internal radar snapshot.

API
- getRadarState()
- getRadarContract()
- getRadarEvents(limit)
- subscribeRadar(listener)

The visual radar remains a separate layer. This milestone establishes the live state/event contract first.
